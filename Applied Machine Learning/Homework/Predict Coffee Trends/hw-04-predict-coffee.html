Explanation of data prep decisions

  1. Variable selection: We kept ONLY variables that would be available before a customer tries coffee D - demographics, general coffee preferences, and consumption habits. We excluded ratings for coffees A, B, and C to stimulate a realistic prediction scenario.

  2. Binary outcome: We converted the personal preference by rating (likely 1-5 scale) to a binary outcome where ratings > 3 indicate the customer liked the coffee. It simplifies interpretation, and is more actionable for business decisions.

  3. Factor conversion: Converting character variables to factors is important for tidymodels to handle categorical variables correctly in recipes.

Justification for resampling choice

  • I chose 10-fold cross-validation because:

    1. Balanced bias variance tradeoff: 10 folds gives good balance between computational cost and reliable performance estimates. Each fold uses 90% of training data, giving stable estimates.

    2. Stratification: We converted the personal preference rating (likely 1-5 scale) to a binary outcome where ratings > 3 indicate the customer liked the coffee. This simplifies interpretation and is more actionable for business decisions.

    3. Standard practice: Converting character variables to factors is important for tidymodels to handle categorical variables correctly in recipes.

Exercise 5

# LASSO

log_spec_tuned <- logistic_reg(
  penalty = tune(), # strength of shrinkage
  mixture = 1 # 1 = LASSO; 0 = ridge; between 0-1 = elastic net
) |>
  set_engine("glmnet") |>
  set_mode("classification")
# recipe :)

log_recipe_tuned <- recipe(liked_coffee_d ~ ., data = coffee_train) |>

  step_unknown(all_nominal_predictors()) |>
  step_impute_median(all_numeric_predictors()) |>

  step_other(all_nominal_predictors(), threshold = 0.005) |>

  step_dummy(all_nominal_predictors()) |>

  step_zv(all_predictors()) |>
  step_normalize(all_numeric_predictors())
# workflow!

log_wflow_tuned <- workflow() |>
  add_model(log_spec_tuned) |>
  add_recipe(log_recipe_tuned)
# tuning grid

set.seed(456)
lambda_grid <- grid_regular(penalty(range = c(-4, 0)), levels = 20)

lasso_tuned_rs <- tune_grid(
  log_wflow_tuned,
  resamples = coffee_folds,
  grid = lambda_grid,
  metrics = null_metrics,
  control = control_grid(save_pred = TRUE)
)
